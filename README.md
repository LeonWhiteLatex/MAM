# Многоагентное моделирование
Система реализована с использованием OpenGL и C++, воспроизводит поведение переубежление людей друг друга в вере. Использует конечные автоматы и условия в итерациях. Нажатие первой кнопки меняет параметр красной команды, обрывая возвращение агентов в это состояние.
